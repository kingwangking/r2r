# Eight operating principles — R2R should fit on one page

1. **Final quality is non-negotiable.** Readiness requires real integrated product evidence, not merely completion of tasks.
2. **Intermediate quality is selectable.** Avoid a universal per-slice release-ready requirement; protect irreversible and high-risk boundaries immediately.
3. **Plan for the whole product.** Ensure capability coverage, credible architectural ownership, reuse decisions and final acceptance before scaling work.
4. **Long execution is a first-class capability.** Agents should carry meaningful campaigns forward without ceremonial approval at every ordinary step; do not pretend inactive sessions run forever.
5. **Steering remains with the developer.** Adjust scope, run length, review depth and architecture based on knowledge, confidence and evidence at any moment.
6. **Review routes important feedback into progress, not endless approvals.** Fix high-impact code/security/data integrity issues promptly, batch ordinary P2/P3, avoid repeat independent review of wording-only changes unless acceptance/safety/traceability changes; choose the cheapest sufficient check. A short **synchronous review** follows meaningful batches in the active workflow; independent deep review can be separately arranged for high-risk questions when actually available, but is not a default infrastructure requirement.
7. **Convergence begins before the end.** Periodic integrated observations and structural correction keep deferred verification debt from becoming unpayable.
8. **Compose with Specs and parallel agents.** Use an existing Spec/SDD for intent and contracts; use parallel implementation when bounded layers support it; R2R manages iteration, frequent human steering and convergence. **Measure accepted outcomes.** Do not optimize lines, green micro-tests, PR counts or reviewer ceremony as substitutes for product usability, cost and final quality.

**Usage rule:** If a proposed new template, status or gate does not improve these principles for a real user, do not add it.
