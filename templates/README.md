# Optional templates — do not manufacture paperwork

- [One-card](one-card.md): smallest combined R2R artifact for a single project.
- [Program](program.md): the whole-product plan and readiness target.
- [Run](run.md): authorization, variable execution horizon and true result.
- [Review](review.md): question or risk-scoped check and affected-path decision.
- [Harden](harden.md): systemic restructuring and final acceptance.
- [Resume](resume.md): actual Git state and truthful handoff.

Copy them only when useful. A targeted question in a chat is also a legitimate steering/review action.
