# Copyable R2R one-card plan

**PLAN**
- Product promise / actual user journey:
- Architecture ownership and protected boundaries:
- Full roadmap / next campaign:
- READY criteria:

**RUN**
- Authorized repo/ref and scope:
- Current horizon (can change anytime):
- Intermediate quality allowed:
- Synchronous quick Review after this meaningful batch; high-risk holds:
- Actual outcome, evidence SHA and next step:

**STEER ANYTIME**
- Developer question or new evidence:
- Keep running / shorten / restructure / deepen review:

**HARDEN**
- Real user journey + observed result:
- Structural issue / fix / relevant regressions:
- Verification debt and outstanding release blockers:
- Owner READY decision: NOT_YET / ACCEPTED_WITH_EVIDENCE

You need not fill every field for a small task. Do not use “accepted” before evidence and actual owner authority.
