# R2R on one card

Copy just this card into a chat or `R2R.md` in an existing project. No extra folders are required.

```text
R2R — Run to Ready

PLAN  Goal: <actual product>
      Whole user journeys: <what must be usable>
      Architecture boundary: <canonical owners / reuse / protected seams>
      Final READY: <real tests + owner acceptance>

RUN   Next meaningful campaign: <scope>
      Long-horizon plan: <link or summary>
      Allowed actions + stops: <authority and safety limits>
      Intermediate quality: <what is allowed to stay imperfect>
      Feedback: <cheapest sufficient review / test>
      Current source and next action: <SHA / file / state>

STEER Developer can question, narrow, extend, redirect, or harden ANYTIME.

HARDEN
      Observe actual user paths → restructure major flaws → fix defects
      → test regressions/security/recovery → repeat until READY.
      Missing test = NOT_RUN. Review is scoped. No hidden background work.
```

**Short version to say aloud:** “Plan the whole thing; keep building within authorization; check what matters; let me steer; keep repairing until the real product is ready.”

Use the expanded [program](../templates/program.md), [run](../templates/run.md) and [harden](../templates/harden.md) templates only if required by the task.
